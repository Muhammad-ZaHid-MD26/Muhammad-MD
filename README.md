## **COMMANDS**

| Command      | Response                            |
|--------------|-------------------------------------|
| `.alive`     | Bot status message (Fire Mode ON!)  |
| `.menu`      | Show all available commands         |
| `.owner`     | Send owner info                     |

## **SETUP INSTRUCTIONS**

1. **Clone the repo:**

```bash
git clone https://github.com/Muhammad-ZaHid-MD26/Muhammad-MD
cd Muhammad-MD/Muhammad_MD_Bot
2. Install dependencies:



npm install

3. Run the bot:



node index.js

4. Scan QR code (first time only)
Session will be saved in auth_info.json
